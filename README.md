# Thailand med små barn

Interaktiv reiseplanlegger for en familieferie på to uker i Thailand.

## Publiser via GitHub og Vercel

1. Opprett et nytt, tomt repository på GitHub.
2. Pakk ut ZIP-filen og last opp innholdet i denne mappen til repositoryet.
3. Gå til [vercel.com/new](https://vercel.com/new), koble til GitHub og velg repositoryet.
4. Vercel gjenkjenner Next.js automatisk. Behold standardinnstillingene og velg **Deploy**.
5. Del den offentlige `.vercel.app`-lenken.

Senere endringer publiseres automatisk når repositoryet oppdateres.

## Lokal kjøring

```bash
npm install
npm run dev
```
